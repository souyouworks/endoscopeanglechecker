# EndoScopeAngleChecker サポートページ

iOSアプリ **EndoScopeAngleChecker**（内視鏡のアングル角度を写真から測定・記録）の
サポートページとプライバシーポリシー。GitHub Pages で公開している。

**このリポジトリは公開。アプリのソースコードは一切含めない。**
開発リポジトリ（非公開）とは完全に別物として扱うこと。

| ファイル | 用途 |
|---|---|
| `index.html` | サポートページ（App Store Connect の「サポートURL」に登録） |
| `privacy.html` | プライバシーポリシー（同「プライバシーポリシーURL」に登録） |
| `style.css` | 共通のスタイル。外部から何も読み込まない |

## 直したいとき

内容の正本は開発リポジトリの `ScopeAngleChecker/プライバシーポリシー.md`。
**あちらを直したら、こちらにも反映すること。**（2か所あるので必ず片方が古くなる）

編集して push すれば、数十秒で公開ページに反映される。

## CSSを直したあとにやること

見た目を変えても古いままに見えるのは、ブラウザが前のCSSを覚えている（キャッシュ）ためです。
GitHub Pages は10分間キャッシュするよう指示しているので、直後は必ず古いものが見えます。

**`版番号をつける.command` をダブルクリックしてから、コミットしてください。**

CSSの中身から計算した番号を `style.css?v=01f88eb1` のように付け直します。
中身が変われば番号も変わるので、ブラウザは新しいものを読み込みます。
中身が変わっていなければ番号も同じままなので、無駄な読み込みは起きません。

※ HTMLと画像・動画には付けていません。HTMLは毎回確認しに行く作りで、
　 画像・動画は中身を変えるときにファイル名ごと変えれば済むためです。
